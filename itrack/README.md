# biscan-vay-eda

A collection of two independent projects.

## Projects

### 1. Biscayne Bay Water Quality — Data Exploration
An FIU Introduction to Data Science lab exploring a 942-row water quality dataset
(salinity, temperature, pH, dissolved oxygen) via a Jupyter notebook and an
interactive Streamlit dashboard.

- `Lab1_Biscayne_Bay.ipynb` — descriptive stats, correlation analysis, outlier detection, visualizations
- `app.py` — Streamlit dashboard (Step 6)
- `biscayne_bay_water_quality.csv` — source dataset
- See `README (1).md` for setup and run instructions.

### 2. iTrack — Job Application Tracker
A personal job/internship application tracker built with Next.js, TypeScript,
Tailwind CSS, and Supabase (Postgres + Auth). Includes a dashboard, sortable
applications table, Kanban board, and per-application detail views.

- See `itrack/README.md` for full setup (Supabase project, schema, environment
  variables) and deployment instructions.

## Tech stack
Jupyter Notebook, Python (pandas, Plotly, Streamlit), TypeScript/Next.js, Supabase/PostgreSQL
